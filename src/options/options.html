How to set up the OAuth client ID
  1. Open the Google Cloud console and create a project (any name).
  2. Go to APIs & Services → Library, search for Google Calendar API and click Enable.
  3. Open Google Auth Platform (the OAuth consent screen) and click Get started. Enter an app name and your email, choose External, and finish.
  4. Under Audience, add your own Google account as a test user. Leave the app in Testing.
  5. Under Data access, click Add or remove scopes and add https://www.googleapis.com/auth/calendar.events.
  6. Under Clients, click Create client. Choose application type Chrome Extension and paste this extension's ID, , as the Item ID. Click Create and copy the Client ID (it ends in .apps.googleusercontent.com).
  7. In the extension's project folder, copy .env.example to .env, set GOOGLE_CLIENT_ID= to that value, and run npm run build.
  8. In chrome://extensions, click the reload icon on Todoist → Calendar, then come back here and click Connect Google Calendar.

The ID above stays the same wherever the folder lives because the manifest includes a fixed public key. While the app is in Testing, Google may ask you to approve access again about once a week. To remove access completely, use your Google Account's third-party connections.
